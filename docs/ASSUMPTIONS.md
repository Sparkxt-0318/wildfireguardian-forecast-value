# Assumptions

Every assumption that could change a conclusion, with its identifier, where it
is enforced, and what would happen if it were wrong. Identifiers are stable and
referenced from docstrings.

| ID | Assumption | Where | If it were wrong |
|---|---|---|---|
| **A-01** | **Flat plane, no terrain, no map projection.** Coordinates are Cartesian km, `+x` east, `+y` north; angles are radians CCW from east. | `fields/geometry.py` | Terrain is the dominant control on real fire spread and on route trafficability. Every geometric conclusion would need re-deriving; none of the *methodological* conclusions would change. |
| **A-02** | **Fire spreads as a constant-rate circular wedge** from each source; arrival time is the minimum over sources. | `fields/front.py` | The hard angular edge is what makes a small heading error flip a decision discontinuously. A smooth (elliptical, probabilistic) front would soften Case 2 into a gradient rather than a cliff, and would smooth the frontier. The *existence* of a skill/value divergence does not depend on it — Cases 1, 3 and 4 survive a smooth front. This is the single strongest assumption in the package. |
| **A-03** | **Sources are exogenous and independent.** Spot ignitions are properties of the world, not stochastically generated by the main front. | `synthetic_decisions/scenarios.py` | Real spotting rate depends on the main fire's intensity, so spot and main-front errors would be more strongly coupled than the copula makes them. Under-couples joint failure. |
| **A-04** | **Fire parameters are constant in time.** No diurnal wind shift, no rate change. | `fields/front.py` | A forecast's error would grow with lead time, coupling the latency and error axes that the frontier sweep treats as independent. The frontier would tilt. |
| **A-05** | **Route exposure is evaluated on sampled points** at `sample_spacing` (default 0.05 km). | `synthetic_decisions/routes.py` | Sampling can only *miss* an exposure between samples, so the computed margin is an upper bound and overrun is under-detected. Error is bounded by roughly `spacing * (1/v + 1/r)` hours. Asserted monotone in `tests/test_decisions.py::test_finer_sampling_can_only_lower_the_margin`. |
| **A-06** | **The community shares one action.** Everyone takes the same route; departures are staggered deterministically. | `synthetic_decisions/scenarios.py` | Per-household decisions would reduce within-world correlation and hence the design effect; the clustering argument would weaken in magnitude but not in kind. |
| **A-07** | **Ties are resolved inclusively for availability and adversely for route success.** A forecast landing exactly at `t_d` is usable; a margin of exactly zero counts as overrun. | `degradation/latency.py`, `synthetic_decisions/routes.py` | Both conventions matter only on a measure-zero set — which is exactly the set the frontier lives on. The opposite conventions are equally defensible and would shift a frontier by less than one grid cell. |
| **A-08** | **Policies are deterministic plug-in minimisers.** The forecast state is treated as if it were the truth. | `synthetic_decisions/policies.py` | This is the *weakest honest* way to use a deterministic forecast and is **not** optimal under uncertainty. A risk-averse or ensemble-based decision maker would extract more value from the same forecast, so every `Delta J` here is a **lower bound** on what that forecast is worth to a better decision maker. |
| **A-09** | **Ensemble members are equally weighted** when forming a burn probability. | `skill_metrics/categorical.py` | Only affects `ensemble_burn_probability` and the Brier score, neither of which feeds a decision in v0.1. |
| **A-10** | **The loss is linear in travel time and a step in burnover**, with a single free parameter `L / c_t`. | `decision_value/loss.py` | A convex near-miss term is available and off by default. Turning it on changes the frontier's shape, which is the point of having it: `loss_ratio_sweep` exists so that sensitivity to this assumption is reported rather than assumed away. |
| **A-11** | **Worlds are independent draws.** Each world's parameters come from a spawned, non-overlapping RNG stream. | `rng.py`, `synthetic_decisions/scenarios.py` | Streams are derived by spawning a `SeedSequence`, never by offsetting an integer seed — offsetting makes nominally independent streams collide, which would silently correlate "independent" worlds. |
| **A-12** | **The baseline is a proximity trigger on the observed burned area.** | `synthetic_decisions/policies.py` | A different baseline gives a different `Delta J`; the value of a forecast is defined only against an alternative. A stronger baseline (e.g. a persistence nowcast) would shrink the blue region of the frontier figure. `check_baseline_is_forecast_free` guarantees at least that the baseline is not a forecast. |
| **A-13** | **The decision is made once, at a fixed time.** | `synthetic_decisions/scenarios.py` | Real protective decisions are revisable. A forecast's *option value* — the ability to wait and re-decide — is entirely absent here, and it is plausibly large. This is the largest conceptual gap (see `SCOPE.md`). |
| **A-14** | **Categorical skill is scored on an explicit grid at an explicit horizon.** | `fields/grids.py`, `synthetic_decisions/scenarios.py` | POD/FAR/CSI depend on the domain the analyst chose. A horizon past the point where the fire leaves the grid saturates CSI at 1 and hides every rate error. Both are explicit, serialised parameters for that reason. |
| **A-15** | **Correlated error follows a Gaussian copula.** | `degradation/combined.py` | No tail dependence: channels that fail together *only* in the tail are not representable, and those are exactly the joint-catastrophe cases. See F-03. |
